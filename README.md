# TurrantFix MVP

A mobile-first Next.js frontend for a doorstep device-repair marketplace with independent technician partners.

## Included

- Original TurrantFix brand system and responsive homepage
- Device search and brand catalogue
- Apple 2026 models including iPhone 18 Pro / Pro Max and iPhone Duo
- Multi-step repair booking flow
- Issue selection and indicative pricing
- Date/time-slot selection
- Customer form validation with React Hook Form + Zod
- Technician-partner acquisition page
- Motion animations with Framer Motion
- No proprietary InstaFix code, copy, logos or image assets

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Stack

- Next.js + React
- TypeScript
- Framer Motion
- Lucide React
- React Hook Form
- Zod
- Plain responsive CSS (no paid UI kit)
